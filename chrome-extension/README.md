# 🧩 CSREP & FACEIT Demo Uploader Pro — Chrome Extension (Manifest V3)

Автономное браузерное расширение для Google Chrome, Microsoft Edge, Brave и Яндекс.Браузера, позволяющее синхронизировать и загружать недостающие демки с FACEIT на csrep.gg в **1 клик**.

---

## ✨ Преимущества расширения перед Node.js / Playwright версией:

1. **Ноль зависимостей:** Не нужен Node.js, npm, консоль PowerShell или терминал.
2. **Мгновенная работа:** Потребляет менее 15 МБ памяти (вместо 600 МБ для Playwright Chromium).
3. **Нативная авторизация без блокировок Cloudflare:** Запросы отправляются напрямую из вашего браузера, где вы уже залогинены в `csrep.gg` и `faceit.com`. Никаких кустарных дампов `cookies.json` и проверок Turnstile.
4. **Многопоточное Range-скачивание:** Скачивает демки с серверов Backblaze/FACEIT параллельными чанками на скорости 6–8 МБ/с прямо в оперативную память.
5. **Кнопка прямо на странице:** При открытии профиля на `csrep.gg` в углу экрана появляется удобный виджет синхронизации с живым индикатором скорости.

---

## 🚀 Установка за 30 секунд (Developer Mode)

1. Откройте любой браузер на базе Chromium (Google Chrome, Microsoft Edge, Brave, Яндекс.Браузер, Opera).
2. В адресной строке перейдите на страницу расширений:
   - В Google Chrome: `chrome://extensions`
   - В Microsoft Edge: `edge://extensions`
   - В Яндекс.Браузере: `browser://extensions`
3. В правом верхнем углу включите переключатель **«Режим разработчика»** (Developer mode).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.
5. Выберите папку:
   ```
   C:\Users\Ak417ytrfg\Documents\antigravity\focused-meitner\chrome-extension
   ```
6. Готово! В панели расширений появится иконка **CSREP & FACEIT Demo Uploader Pro**.

## 🎯 Как пользоваться

### Способ 1. Через значок расширения (Popup Дашборд)
1. Нажмите на значок расширения в правом верхнем углу браузера (можно закрепить булавкой 📌).
2. Проверьте ваш **Steam ID (64-bit)** (по умолчанию уже указан).
3. Выберите количество страниц для проверки (по умолчанию 3) и количество параллельных потоков (по умолчанию 4).
4. Нажмите **⚡ Синхронизировать демки**.
5. Следите за процессом в реальном времени: отображается процент, скорость (MB/s) и подробный журнал.

### Способ 2. Прямо на сайте csrep.gg
1. Откройте страницу вашего профиля или матчей на `https://csrep.gg/player/76561198434644264`.
2. В правом нижнем углу страницы появится стильный оранжевый виджет **CSREP & FACEIT SYNC**.
3. Нажмите кнопку **⚡ Синхронизировать** прямо на странице.
4. Прогресс-бар и скорость будут отображаться прямо поверх сайта!
